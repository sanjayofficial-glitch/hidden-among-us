# Hidden Agents - Premium UI Integration Plan

## Context

The game has a fully functional backend and basic Tailwind UI. The user provided a premium design system with canvas particles, glassmorphism, cinematic animations. Goal: integrate premium visuals while maintaining game logic.

## Design Decisions
- **Role naming**: Map abbreviations (spy/det/cit) in components, keep types as-is
- **Discussion**: Reddit comments integration (fetch from post thread)
- **Canvas background**: Always on, no toggle

## Implementation Steps

### Step 1: Design System Foundation
**Create `src/client/components/DesignSystem.tsx`** (~400 lines)
- `CustomStyles` - CSS animations, glassmorphism, keyframes
- `LivingBackground` - Canvas particle system (always on)
- `PremiumButton` - Gradient buttons with hover effects
- `Avatar` - Role-based emoji avatars with badges
- `LoadingText` - Rotating messages

### Step 2: Update Shared Types
**Modify `src/shared/types.ts`**
- Add `role_reveal` and `elimination_reveal` to GamePhase union

### Step 3: Update Server Phase Transitions
**Modify `src/server/storage/rooms.ts`**
- After `startGame()`: set phase to `role_reveal` instead of `night`
- After night resolution: go to `discussion` (existing)
- After voting resolution: go to `elimination_reveal` before `reveal`
- Add `advanceFromRoleReveal()` and `advanceFromEliminationReveal()` functions

### Step 4: Add Reddit Comments API
**Modify `src/server/routes/game.ts`**
- Add `GET /api/game/comments` endpoint
- Fetch Reddit comments from the post using `reddit.getComments()`
- Return formatted comment list for discussion phase

**Modify `src/client/hooks/useGameState.ts`**
- Add `fetchComments()` method
- Poll comments during discussion phase

### Step 5: Rewrite All Screens

**Rewrite `src/client/screens/Lobby.tsx`**
- Premium glass cards, mystery card, staggered animations
- Use Avatar component, PremiumButton

**Rewrite `src/client/screens/RoleReveal.tsx`** (was orphaned, now active)
- Multi-stage cinematic: blackout → scan → boom
- Spy gets heartbeat, detective gets radar sweep
- Role-specific colors and descriptions

**Create `src/client/screens/EliminationReveal.tsx`**
- Spotlight → flash → role stamp animation
- Cinematic shake on reveal

**Rewrite `src/client/screens/NightPhase.tsx`**
- Role-themed with selection rings
- Spy: red theme, "Eliminate Target"
- Detective: blue theme, "Investigate Suspect"
- Citizens: sleeping animation

**Rewrite `src/client/screens/DiscussionPhase.tsx`**
- Fetch real Reddit comments from post
- Display as chat messages with avatars
- Investigation intel card for detective
- Timer header with glow effects

**Rewrite `src/client/screens/VotingPhase.tsx`**
- 3D flip cards for vote selection
- Progress bar showing votes cast
- Vote counts per player

**Rewrite `src/client/screens/GameEnd.tsx`**
- Victory/defeat with XP, badges, role reveals
- Play again and leaderboard buttons

**Rewrite `src/client/screens/Leaderboard.tsx`**
- 3D podium layout (1st/2nd/3rd)
- Crown animation for #1
- Player stats with progress bars

### Step 6: Integrate Everything in Game.tsx
**Rewrite `src/client/game.tsx`**
- Add `LivingBackground` with phase prop
- Wire all premium screens
- Update phase flow: Lobby → RoleReveal → Night → Discussion → Voting → EliminationReveal → Reveal → (repeat or end)
- Pass comments data to DiscussionPhase

### Step 7: Update Splash Screen
**Rewrite `src/client/splash.tsx`**
- Premium styling with LivingBackground
- Glassmorphism card, Avatar, PremiumButton

### Step 8: Update Preview
**Rewrite `preview.html`**
- Update all screens to match new premium design
- Add RoleReveal and EliminationReveal screens
